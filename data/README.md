# Data

This folder will hold the project's raw, sample, and processed datasets. No data files have been added yet.

## Planned sources

- **Ballon d'Or voting results:** Wikipedia pages for each award year (compiled from France Football rankings), including rank, player, club, and voting points. The 2020 award was not given because of the COVID-19 pandemic.
- **Player and team performance:** public sources such as FBref and Transfermarkt (goals, assists, minutes, competitions, and club/international trophies).

These sources will be documented in more detail, including the expected schema and how to replace any sample files, once data collection begins.

Any synthetic or placeholder data used only to demonstrate the pipeline will be clearly labelled and kept separate from verified historical voting records.
