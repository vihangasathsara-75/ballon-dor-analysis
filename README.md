# Ballon d'Or Voting Analysis

## Overview

This project investigates the relationship between player performance, team achievements, and Ballon d'Or voting outcomes.

The goal is to explore which measurable factors are associated with Ballon d'Or voting results and to investigate whether historical voting outcomes can be modelled using player and team performance data.

## Research Question

What measurable individual and team-performance factors are associated with Ballon d'Or voting outcomes?

## Objectives

- Collect and combine historical Ballon d'Or voting and player performance data.
- Clean and prepare the data for analysis.
- Explore patterns and relationships between player performance and voting outcomes.
- Identify factors associated with higher Ballon d'Or voting points.
- Develop machine learning models to investigate whether voting outcomes can be predicted.
- Evaluate and interpret the results.
